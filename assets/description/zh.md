# Adaptive Enemy AI（自适应敌人 AI）

> **⚠️ 需求说明**：本模组需要 **Harmony 模组**。请先安装 Harmony。

通过分析玩家的装备与行为模式，改变敌人战斗方式的模组。当不存在初始行为模式时，敌人会主要根据玩家的装备行动。随着模式累积，会为玩家构成更具挑战性的战斗环境。

## 🔄 v1.3.9 更新内容

- **修复隔墙感知**：修复了敌人隔着墙壁也能察觉、追踪并攻击玩家的问题。现在只有**真正看见玩家时**才会瞄准和射击。
- **对声音的反应**：听到枪声后，敌人会**前往声音发出的位置并在附近搜索**。仅凭声音不会追踪玩家的当前位置。
- **失去视野后搜索**：失去视野时，敌人会前往**最后看到玩家的位置**查看一段时间，然后返回巡逻。
- **视野角度**：敌人现在有正面视野和余光。从背后接近会更晚被发现。
- **反应时间**：敌人发现玩家到开火之间有了短暂的反应时间。模组学习到的自适应数值越高，这段时间越短。

## ✨ 主要功能

- **敌人 AI 校准**：根据装备与行为，敌人的**战斗判断**（攻击型判断 ↔ 防御型判断）会实时变化。

**影响因素**
- **装备**：所持武器与防具
- **战斗时行为模式**：会学习并反映战斗发生时**如何移动与攻击**。
  - **移动**：走路、冲刺接近，以及移动时长/距离
  - **移动模式学习**：学习你如何接近敌人，并反映到敌人 AI 的移动修正中。
  - **攻击**：反应速度、开火频率（连射或谨慎射击）、瞄准精度、追踪与遗忘玩家的时间
  - **回避**：检测到可能命中的子弹或近战挥击时是否尝试闪避冲刺及其频率
  - **发射节奏反制**：预读你的开火时机，提前移动以增加瞄准难度。
  - **时间衰减校正**：保存的模式越久权重越低，使近期玩法更易被反映。

## 🎯 按装备的敌人应对

敌人根据玩家的武器与**防具（护甲）**调整战斗判断。（以对 AI 有利的战斗方式反应。）

- 玩家持**有利武器**时 → 敌人**攻击型判断**（积极施压）
- 玩家持**不利武器**时 → 敌人**防御型判断**（保持距离、优先回避）
- 玩家防具**高**时 → 敌人**防御型判断**
- 玩家防具**低**时 → 敌人**攻击型判断**

## 📋 说明

- 本模组尚处于实验阶段，敌人的战斗判断可能比预期更偏向攻击或更偏向防御。游玩后的感受反馈对下一版本很有帮助。
