# Adaptive Enemy AI（自適應敵人 AI）

> **⚠️ 需求說明**：本模組需要 **Harmony 模組**。請先安裝 Harmony。

分析玩家的裝備與行為模式，據此改變敵人戰鬥方式的模組。當不存在初始行為模式時，敵人會主要根據玩家的裝備行動。隨著模式累積，會為玩家構成更具挑戰性的戰鬥環境。

## 🔄 v1.4.0 更新內容

- **聲音不再把敵人引到你身邊**：一聲槍響只會開始一次朝聲源位置的搜索。搜索結束前（8 秒）的後續槍聲不會改變方向；結束後再前往最新的聲源。敵人走向的是你*曾經*所在的位置，而不是目前位置。
- **不再貼身**：持槍敵人會保持武器的最小射程（手槍/衝鋒槍 2 公尺、霰彈槍 2.5 公尺、突擊步槍 3 公尺、戰鬥步槍/機槍 4 公尺、狙擊槍 5 公尺），不再貼到身上。近戰敵人不變。
- **瞥一眼不會觸發衝鋒**：處於警戒但沒有目標的敵人，需要通過反應延遲的確認視野後，模組才會開始把它引向玩家。與開火採用同一標準。
## ✨ 主要功能

- **敵人 AI 校準**：依裝備與行為，敵人的**戰鬥判斷**（攻擊型判斷 ↔ 防禦型判斷）會即時變化。

**影響因素**
- **裝備**：所持武器與防具
- **戰鬥時行為模式**：會學習並反映戰鬥發生時**如何移動與攻擊**。
  - **移動**：走路、衝刺接近，以及移動時長／距離
  - **移動模式學習**：學習你如何接近敵人，並反映到敵人 AI 的移動修正中。
  - **攻擊**：反應速度、開火頻率（連射或謹慎射擊）、瞄準精度、追蹤與遺忘玩家的時間
  - **迴避**：偵測到可能命中的子彈或近戰揮擊時是否嘗試閃避衝刺及其頻率
  - **發射節奏反制**：預讀你的開火時機，提前移動以增加瞄準難度。
  - **時間衰減校正**：儲存的模式越久權重越低，使近期玩法更易被反映。

## 🎯 依裝備的敵人應對

敵人根據玩家的武器與**防具（護甲）**調整戰鬥判斷。（以對 AI 有利的戰鬥方式反應。）

- 玩家持**有利武器**時 → 敵人**攻擊型判斷**（積極施壓）
- 玩家持**不利武器**時 → 敵人**防禦型判斷**（保持距離、優先迴避）
- 玩家防具**高**時 → 敵人**防禦型判斷**
- 玩家防具**低**時 → 敵人**攻擊型判斷**
